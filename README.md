# Coaching Website Demos

Five complete, themed demo websites for one fictional coaching institute (Disha Classes, Indore) — built with Next.js 14 + Tailwind.

- `/` — showcase landing (pick a design)
- `/scholar` Classic Trust · `/orbit` Modern Animated · `/nest` Warm Foundation · `/apex` Elite Dark · `/chalk` Chalkboard Editorial
- Each theme: Home, About, Courses, Faculty, Results (Toppers), Admission & Contact + free-demo-class WhatsApp booking, Hindi/English toggle

**Rebrand for a client:** edit `lib/config.ts` (name, city, phone, WhatsApp, map).

```bash
npm install
npm run dev
```
